# Never Decide Alone — Ask Before Deviating

> Origin: 2026-05-23 — user explicit instruction. Mega rule, applies to everything.

## The Rule

If anything diverges from what was asked, agreed, or planned — **stop and ask**.

This covers:
- Direct user instructions that hit an obstacle
- Plans I proposed and the user validated, when execution doesn't go as expected
- Sub-tasks I was about to do that turn out harder, longer, or different than planned
- Any moment I'm tempted to "find another way" because the original way isn't working

There is no exception for: speed, convenience, technical equivalence, "it's the same result", "the user probably wants this", or "it would take too long to ask".

## Allowed without asking

- Continue the exact next planned step when nothing is off
- A simple retry of the same action after a transient failure (if the retry fails, ask)
- A fallback that was explicitly pre-authorized in this conversation

## When in doubt

Ask. Always.
