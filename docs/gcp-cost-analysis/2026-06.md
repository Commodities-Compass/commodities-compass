## 4. Analyse détaillée par service GCP

### 4.1 Artifact Registry — €21.09 net (+570 %) 🔴 NOUVEAU #1

**Ce qui tourne** : 1 repo Docker `commodities-compass` (europe-west9) avec 3 images (`backend`, `frontend`, `jobs`).

**Anomalie** :
- Taille repo mesurée : **~296 GB** (`gcloud artifacts repositories describe … --format='value(sizeBytes)'`).
- Nombre de versions retenues : **162 `jobs` + 181 `backend` + 191 `frontend` = 534 versions**, dont des taggées remontant au **2026-03-30** (premier déploiement).
- Facturation : 100 % SKU *Artifact Registry Storage* (confirmé par Gemini Cloud Assist). ~296 GB × $0.10/GB/mois ≈ €27 en régime établi — juin facture €21.09 car le repo a grossi *pendant* le mois.

**Root cause** — cleanup policy structurellement inefficace :
- `keep-latest-10` (KEEP) ne supprime rien, il *protège* d'un DELETE.
- `delete-untagged` ne matche que les images **untagged**.
- Le CI tag chaque push avec le SHA git → **toute image est taggée** → aucun DELETE ne l'a jamais purgée → accumulation non bornée.

**Fix (PR #56)** : ajout d'une policy `delete-old-versions` (DELETE tout > 30j) + floor `keep-minimum-versions` (KEEP 5). Livré avec `cleanup_policy_dry_run = true` pour valider le compte de purge avant suppression réelle.

**Effet attendu** : 296 GB → ~20-30 GB → **€21 → ~€2-3/mois**.

**À vérifier après apply** :
```bash
gcloud artifacts repositories describe commodities-compass \
  --location=europe-west9 --project=cacaooo --format='value(sizeBytes)'
```

### 4.3 Compute Engine — €14.06 net (−4.6 % usage vs mai)

**Ce qui tourne** :
- `cc-bastion` : e2-micro, 10 GB pd-standard, **status TERMINATED**, 0 snapshot. Start-on-demand (dernier cycle : 3 min ce matin). ✅ P0 avril appliqué.

**Révélation** : le bastion est stoppé la plupart du temps, pourtant Compute reste à €14. Le SKU incriminé par Gemini en mai (« E2 Instance Core running in Paris ») = les **instances e2-micro du VPC connector**, facturées ici et non dans « Networking ». → **le VPC connector représente ~€10-12/mois de ce poste**, le bastion ~€1-2.

**Conséquence** : le stop du bastion (P0 avril) a moins rapporté qu'espéré (~€2-4, pas €16) car le connector domine ce poste. Le vrai levier Compute = **Direct VPC Egress** (§5.3).

### 5.3 P0 — Direct VPC Egress (nouveau levier prioritaire)

Le `cc-vpc-connector` maintient **2× e2-micro idle 24/7** (~€10-12/mois, caché dans Compute Engine — cf §4.3). **Direct VPC Egress** (GA sur Cloud Run) supprime cette infra fixe : billing au prorata du trafic seulement.

**Procédure** :
1. Créer un subnet dédié pour Direct VPC Egress.
2. Migrer services + 19 jobs : remplacer `--vpc-connector` par `--network`+`--subnet` + `--vpc-egress=private-ranges-only`.
3. Tester la connectivité Cloud SQL en staging.
4. Supprimer `cc-vpc-connector` une fois validé.

**Économie attendue** : €10-12/mois (revu à la hausse vs les €5-8 d'avril — le coût est maintenant visible car non masqué par les crédits). PR séparée à venir.

```bash
# Artifact Registry — taille + versions
gcloud artifacts repositories describe commodities-compass \
  --location=europe-west9 --project=cacaooo --format='value(sizeBytes)'
for img in jobs backend frontend; do
  gcloud artifacts docker images list \
    europe-west9-docker.pkg.dev/cacaooo/commodities-compass/$img \
    --include-tags --format='value(version)' | wc -l

# Bastion — statut + machineType
gcloud compute instances describe cc-bastion --zone=europe-west9-a --project=cacaooo \
  --format='yaml(machineType,status,lastStartTimestamp,lastStopTimestamp)'

# Inventaire
gcloud run jobs list --project=cacaooo --region=europe-west9
gcloud scheduler jobs list --project=cacaooo --location=europe-west1
gcloud secrets list --project=cacaooo
```

- Tous les coûts en € (TVA incluse).
- **Distinguer usage brut vs net facturé** : jusqu'à mai, ~€49/mois de crédits promo masquaient la facture. Depuis juin, les crédits sont épuisés (−€4.73) → le net ≈ l'usage brut. Comparer les mois sur l'**usage brut** pour la vraie tendance.
- Les coûts **LLM (OpenAI)** sont hors facture GCP — non couverts par ce rapport.
- Pour un breakdown exact par SKU/label, activer le BigQuery billing export (§5.4).
