Gauge Styles — Editorial

5 approaches for Compass CC dashboard indicators

Style 1 — Bullet Chart

Horizontal bar with zone backgrounds and a bold marker line. Maximum data-ink ratio.

Style 2 — Dot Scale

Seven dots across three zones. Only the active dot is filled. Like a rating system.

Style 3 — Number + Context Bar

Typography-driven: the number IS the gauge. A thin bar below shows position.

Style 4 — Ruler Scale

Minimal number line with tick marks at zone boundaries and a triangle marker.

Style 5 — Stacked Typography

Pure typography. No bars, no graphics. Label, value, and status pill.
